# Student Management System

A Python-based Student Management System with separate Admin and Student login functionality. The project is developed using Object-Oriented Programming (OOP) and basic Python concepts.

## Features

### Admin Login
- Add new students
- View all student records
- Search students by ID
- Update student details
- Update marks and attendance
- Delete student records
- View class statistics

### Student Login
- View personal profile
- Check marks and results
- Calculate percentage
- View attendance
- Change password

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Functions
- Lists
- Dictionaries
- Sets
- Loops
- Conditional Statements
- String Operations
